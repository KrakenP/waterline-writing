# waterline-content-router

Thin orchestration Skill for turning one completed Waterline research package into multiple platform-native drafts.

It does not replace the three editorial style Skills. It combines:

```text
Truth Pack + Style Skill + Platform Adapter = Platform Draft
```

Default research root on macOS:

```text
/Volumes/NAS/quant/Waterline-Research
```

See `../../workflows/distribute.md` and `../../config/routes.yaml`.
