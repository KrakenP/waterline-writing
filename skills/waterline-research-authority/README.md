# Waterline Research Authority Skill

Turn a Master Research package into content that makes readers conclude: **“Waterline has done the work.”** The product is not a raw report; it is a readable, source-traceable research artifact.

This Skill lives inside `waterline-writing` and consumes the **same Waterline Master Research** as the other writing Skills while producing a different audience contract. Facts and uncertainty stay fixed; packaging changes.

## Files
- `SKILL.md` — executable editorial instructions
- `manifest.json` — lightweight metadata
- `../../research/platform-playbook.md` — six-platform defaults
- `../../research/benchmark-accounts/` — 120-account benchmark
- `../../research/benchmark-findings.md` — extracted mechanisms
- `../../research/creator-benchmark-report.md` — full 120-account research report
- `../../research/source-ledger.md` — sources/confidence
- `../../research/compliance-cn.md` — finance-content guardrails
- `examples/physical-ai.md` — worked format example
- `scripts/validate.py` — lightweight validation

## Quick use
```text
Use the waterline-research-authority Skill.
Platform: 小红书 / 抖音 / B站 / 公众号 / 雪球 / 微博
Goal: ...
Audience: ...
As-of: ...
Input: <Master Research>
```

## Benchmark basis

Includes a 120-account operating benchmark (20 samples × 6 platforms) from public ranking snapshots and strategically relevant comparators. It is not represented as an official all-platform rank. See `../../research/source-ledger.md`.

## Waterline compatibility

This Skill is downstream of research. It may compress, reorder and re-express eligible claims; it may not upgrade confidence, erase dissent, invent sources, approve publication, or create portfolio authority.
