# Douyin adapter

## Primary job
Reach through one sharp financial or industrial puzzle.

## Default unit
30–120 seconds unless the user requests a longer format.

## Packaging
- Hook: conflict, reversal, strange number, or one sharp question in the first 1–2 lines.
- Evidence: 2–4 decisive facts.
- Structure: visible puzzle → mechanism → payoff / implication.
- Visuals: shot list, chart/B-roll suggestions, and on-screen text. Never present fabricated imagery as evidence.
- CTA: follow for the next part or point to the full Waterline brief.

## Native output
- 5 hook/title options.
- recommended hook.
- spoken script.
- shot/B-roll list.
- on-screen text.
- source trace.
- CTA and compliance flags.

## Do not
- invent scenes or quotes.
- sacrifice claim type for drama.
- overload the script with jargon before the audience cares about the puzzle.
