# Weibo adapter

## Primary job
Timeliness, habit, and fast idea distribution.

## Default unit
- 100–500 Chinese characters for a single post, or
- a concise thread when one post would destroy the causal chain.

## Packaging
- Hook: immediate inference or one surprising data point.
- Evidence: one key source/data point per post when possible.
- Pacing: concise, current, conversational but not casual with facts.
- CTA: follow, read the thread, or continue to long-form Waterline research.

## Native output
- 3–5 opening options.
- post or thread.
- source trace for material factual claims.
- CTA and compliance flags.

## Do not
- compress away material qualifiers.
- create certainty from a preliminary update.
- use engagement bait that changes the research meaning.
